# Flags

260 round country and region flags, 24px, used in the country picker (radio list), phone-number prefixes and locale settings.

The files are numbered in the order of the source Figma frame (`flag-001` … `flag-260`), not by country, because the export didn't keep the layer names. Map them to ISO 3166 codes before using them in code. Always show the country name next to a flag, because many flags look alike at 24px.
